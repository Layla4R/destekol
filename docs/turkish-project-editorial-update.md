# Turkish project terminology update — 9 October 2026

Updated the Turkish CMS translation for the six project cards on `/tr/projects`, plus the titles, descriptions and main text of their six linked project pages. The revised wording to reuse in the editor is in `turkish-project-copy.json`.

- Drinking-water distribution: **Kamplarda temiz içme suyu dağıtımı**, rather than irrigation (`Su Sulama`). WASH is **Su, sanitasyon ve hijyen**.
- Field kitchens: **Sahra mutfakları**, rather than agricultural field kitchens (`Tarla mutfakları`). Financial/resource constraints are described as **maddi imkânların sınırlı olması**, never a beneficiary's lack of ability (`yeteneksizlik`). The existing daily-meal scale is explicitly a target, not a verified delivered count.
- Food assistance: **gıda kolisi dağıtımı** and **yemek desteği**. Replaced literal lifeline rhetoric (`cankurtaran halatı`) with the actual assistance and daily nutrition needs.
- Flour milling: **un değirmeni desteği**, with local production and income goals.
- Patient assistance: **sağlık ve kişisel bakım kitleri desteği**, describing supplies rather than implying the association delivers comprehensive clinical treatment.
- Water detail section terminology now describes purified drinking water rather than sterile medical water.

This is an editorial correction based on the existing campaign descriptions. It does not add new beneficiaries, delivery totals, partnerships, clinical credentials or evidence. Formal sign-off by a native Turkish editor or a health specialist has not been represented as completed.

Changes were applied only to `destekol.PageTranslation` with locale `tr`, preserving section IDs, images, links, order and other locales. Other-locale translation content was verified unchanged by a before/after hash. These CMS content changes are available without a code deployment. Public HTML is checked for corrected card titles and absence of the erroneous terms.
