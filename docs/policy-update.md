# تحديث سياسات Destek Ol

تاريخ التحديث: 7 أكتوبر 2026.

استُبدلت نصوص السياسات القديمة المعروضة في الموقع بالسياسات التسع التي قدمها المستخدم. حُفظ النص التركي كاملًا في `data/policies/tr.json`، مع ترجمة جميع العناوين والفقرات والجداول إلى العربية والإنجليزية والفرنسية. لم تُحذف شروط أو استثناءات أو حقوق من النصوص الأصلية.

| الوثيقة | مسار الصفحة بعد رمز اللغة |
| --- | --- |
| الخصوصية وحماية البيانات | `/privacy` |
| شروط استخدام الموقع | `/terms` |
| التبرعات والإلغاء والاسترداد | `/refund-policy` |
| ملفات تعريف الارتباط | `/cookie-policy` |
| مكافحة غسل الأموال وتمويل الإرهاب والاحتيال والامتثال للعقوبات | `/aml-policy` |
| الشكاوى والملاحظات | `/complaints` |
| الشفافية المالية واستخدام التبرعات | `/financial-transparency` |
| حقوق المحتوى واستخدام العلامة والمعلومات الرسمية | `/license` |
| الإفصاح وفق KVKK | `/kvkk` |

مسار `/how-we-use-donations` الحالي يعرض السياسة المالية الجديدة كاملة كذلك، للحفاظ على الروابط السابقة. يعرض التذييل السياسات التسع دون تكرار السياسة المالية. وتستخدم الصفحات النصوص الجديدة مباشرة بدلًا من المحتوى القديم المخزّن في نظام إدارة المحتوى؛ لا يلزم وجود سجل سابق لصفحة KVKK. أُدرجت الروابط في خريطة الموقع، وأصبح مساعد الموقع يستند إلى النصوص الجديدة حتى عندما لا يوجد سجل قديم للسياسة.

السياسات الجديدة تفصل بين التبرع والشراء أو الاستثمار، وتوضح حالات مراجعة الاسترداد، وتربط استخدام التبرعات المقيّدة بشروط الحملة والقانون. كما توضح حقوق صاحب البيانات والأسس القانونية وقيود مشاركة المعلومات الحساسة، دون نقل الادعاءات القديمة المتعلقة بامتثال GDPR أو المواعيد المضمونة للرد.

أُضيف بند توضيحي واحد إلى سياسة الاسترداد وبند واحد إلى شروط الاستخدام، باللغات الأربع. يوضحان معالجة الإلغاء والاسترداد عبر PayTR، وتفاوت زمن ظهور المبلغ حسب البنك والبطاقة، واعتماد تأكيد الدفع على إشعار المعاملة المتحقق منه. صيغت الإضافات بشرط تفعيل PayTR، دون ادعاء تفعيلها أو قبول حساب المؤسسة أو ضمان موعد استرداد ثابت.

مراجع الإضافات: [إجراءات PayTR للمدفوعات والاسترداد](https://www.paytr.com/destek-merkezi/odemeler)، [إشعار نتيجة الدفع](https://dev.paytr.com/iframe-api/iframe-api-2-adim).

التحقق: مقارنة الفقرات الأصلية الـ278 من ملفات DOCX بالمصدر التركي دون أي فقرة مفقودة، ومطابقة الأقسام والفقرات وأبعاد الجداول في الترجمات، وفحص ظهور كامل المحتوى في HTML واتجاه العربية وروابط KVKK. يمكن تشغيل اختبارات السياسات باستخدام `node scripts/test-policies.cjs`.

هذا تحديث لملفات المشروع المحلي. لم تتضمن المهمة نشر نسخة جديدة على الاستضافة أو تعديل سجلات قاعدة البيانات القديمة.
